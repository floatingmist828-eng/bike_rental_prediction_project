# 共享单车租借量预测任务说明
## 一、任务概述
本任务为**回归预测任务**，基于小时级历史数据，结合日期、时间、气象等多维特征，预测单小时内共享单车总租借量 `cnt`。
评价指标采用**均方误差（MSE）**，MSE 数值越小，代表模型预测效果越优。

## 二、数据集说明
数据集包含两个核心文件：
1. `train.csv`：训练集，含全部特征与真实标签 `cnt`
2. `test.csv`：测试集，仅含特征，无目标值 `cnt`，需完成预测

### 字段详情（train.csv & test.csv 共有字段）
| 字段名 | 字段含义 |
| ---- | ---- |
| ID | 样本唯一编号 |
| dteday | 具体日期 |
| season | 季节 |
| yr | 年份 |
| mnth | 月份 |
| hr | 小时 |
| holiday | 是否为节假日 |
| weekday | 星期几 |
| workingday | 是否为工作日 |
| weathersit | 天气状况 |
| temp | 归一化温度 |
| atemp | 归一化体感温度 |
| hum | 归一化湿度 |
| windspeed | 归一化风速 |
| cnt | 共享单车租借总量（**仅训练集存在，预测目标**） |

## 三、任务目标
使用 `train.csv` 训练回归模型，对 `test.csv` 所有样本的租借量 `cnt` 进行预测，输出标准结果文件。

## 四、提交要求
### 1. 提交文件
文件名称：`submission.csv`

### 2. 文件格式规范
- 固定两列：`ID`、`cnt`，首行为表头 `ID,cnt`
- `ID` 必须和 `test.csv` 样本编号一一对应，不可缺失、乱序
- `cnt` 为预测数值，支持整数/小数格式

### 格式示例
```csv
ID,cnt
13904,300
13905,400
13906,600
13907,300
```

## 五、评价指标
采用**均方误差 MSE** 作为唯一评价标准，计算公式：
$$
MSE = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2
$$
- $n$：测试集样本总数
- $y_i$：第 $i$ 个样本的真实租借量
- $\hat{y}_i$：第 $i$ 个样本的模型预测租借量

**规则**：MSE 数值越低，模型精度越高，排名越靠前。
